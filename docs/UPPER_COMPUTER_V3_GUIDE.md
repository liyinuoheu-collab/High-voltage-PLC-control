# Donut-HASEL 上位机 V3 操作说明

## 1. 连接

1. 高压侧按实验安全流程完成接线，驱动板使用独立 7.4 V 供电。
2. 板端 `PB6/TX → USB-TTL RX`，`PB7/RX → USB-TTL TX`，`GND → GND`。
3. USB-TTL 必须使用 3.3 V TTL；不要连接 USB-TTL 的 VCC。
4. 将 USB-TTL 插入电脑，启动程序，点击“刷新”，选择 COM 口并连接。

PB6/PB7 是 USART1 运行串口；烧录时使用的 CLK/IO 分别是 SWCLK/SWDIO，二者不是同一组接口。

## 2. 界面

主图始终显示两条电压曲线：

- `Vcmd`：板端在当前路由实际下达的高压幅值；
- `Vreal`：板载分压 ADC 换算的反馈幅值。

下方独立时序图显示 `LEFT` 与 `RIGHT` 逻辑状态。它们是板端命令/路由状态，不是用外部高压探头直接测得的两路电压。

“实验参数”和“设备与诊断”默认收起，点击标题展开。参数只在板端待机时可编辑，应用后以之后收到的遥测为最终可信值。

## 3. 参数和控制

- 电压：4.0–7.0 kV，0.5 kV 步进；
- 波形：HOLD 或 SQUARE；
- 频率：0.2 / 0.4 / 0.8 / 1.6 Hz；
- 占空比：25 / 50 / 75%；
- 左右相位差：0 / 90 / 180°；
- 总时长：10 / 20 / 30 / 60 s 或一直驱动；
- 末端清荷：3 kV、200 ms，可开关。

点击“应用待机参数”后，软件逐项发送命令。点击“启动驱动”开始，点击“正常停机”结束；红外 `CH+` 与 `CH` 仍可使用。

故障锁定后，“启动驱动”不可用。点击“故障解锁”需要确认；解锁不会自动启动，只返回待机。遥控也可按 `CH` 后在 3 s 内按 `CH+` 解锁，同样不会立即启动。

## 4. 疑似击穿筛选

“疑似击穿自动停机”是电脑端筛选，默认开启。它根据 Vcmd/Vreal 突降、持续跟踪偏低、路由稳定状态及 LEFT/RIGHT 组合生成：

- `P2P_GAP_SUSPECT`：左右状态不同，优先提示两正极间空气间隙风险；
- `HV_PATH_SUSPECT`：同步高态或 HOLD 下的高压路径风险；
- `SWITCHING_SUSPECT`：处于切换窗口；
- `UNLOCATED_ARC`：数据不足以定位。

判据只能标记“疑似”，不能代替声音、图像、外部高压探头或绝缘检查。开启时，确认的疑似事件只发送一次 `FAULT,PC_ARC`，板端进入锁定；关闭时仍记录和报警，但不自动停机。

板端硬保护始终独立启用，前端开关不能关闭它。不上位机时，不存在电脑端疑似击穿自动停机，因此也不会因电脑判据频繁停机；板端严重故障保护仍然工作。

## 5. 记录与时间对齐

记录时长没有软件设限，只受磁盘空间、USB 稳定性和电脑休眠影响。每个会话严格生成五个文件：

- `serial_raw.log`：未经改写的串口原始字节；
- `telemetry_raw.csv`：全部字段、电脑 ISO 时间、`HH:mm:ss.fff`、单调时间和板端毫秒 tick；
- `events.csv`：命令、坏帧、丢帧、断线和疑似击穿分析事件；
- `metadata.json`：端口、版本、自动停机开关、行数和停止原因；
- `simple_export.csv`：电脑时间、阶段、设定/实际电压、相位、LEFT/RIGHT 和故障码。

SG3150 测量结束后再导出数据时，可用 `simple_export.csv` 的电脑 `HH:mm:ss.fff` 与传感器文件的时间粗对齐。由于两套设备没有硬件触发，该方法不应被表述为严格毫秒同步。

## 6. 高压安全

- 串口断开、软件关闭、停止记录均不等于高压停止。
- 紧急情况切断板卡 7.4 V 电源并使用额定耐压、限流的泄放路径。
- 禁止直接短接高压输出。
- 开始实验前先确认负载、绝缘距离、接地、人员隔离和急停/断电路径。
